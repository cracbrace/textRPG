# TextRPG — 勇者屠龙

一款基于控制台的 Java 文本 RPG 游戏。玩家扮演勇者，从新手村出发，穿越迷雾森林、黑暗洞穴，最终挑战魔王城堡中的绝望黑龙。

---

## 游戏流程

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   新手村 V    │ ──→ │  迷雾森林 F   │ ──→ │  黑暗洞穴 C   │ ──→ │  魔王城堡 T   │
│  与老村长对话  │     │  击败史莱姆    │     │  击败骷髅战士   │     │  BOSS战：黑龙  │
│  获得新手药水  │     │  获得强化果实   │     │  对话女神获神技 │     │  通关结局     │
└──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
```

### 阶段一：新手村

- **出生点**：新手村 `V`（2×2 区域），地图左下角
- **NPC**：老村长
- **对话**：
  > "年轻的勇者啊，传说森林深处的古堡里有一条恶龙，但你现在的实力还不足以击败它。去森林里历练一番吧！"
- **地面物品**：新手药水（恢复 50 HP），输入 `take` 捡起

### 阶段二：迷雾森林

- **地点**：迷雾森林 `F`，地图随机位置
- **描述**："空气中弥漫着雾气，周围偶尔传来奇怪的叫声。"
- **遭遇敌人**：森林史莱姆（HP: 25, ATK: 8, DEF: 0, 经验: 10）
- **地面物品**：强化果实（四维 +20），输入 `take` 捡起

### 阶段三：黑暗洞穴

- **地点**：黑暗洞穴 `C`，地图随机位置
- **描述**："阴暗潮湿，看起来非常危险。"
- **遭遇敌人**：洞穴骷髅（HP: 70, ATK: 18, DEF: 8, 经验: 45）
- **NPC**：女神
- **对话**："你的勇气令人赞赏。愿赐你神技，以斩尽黑暗。"
- **特殊奖励**：对话后自动习得 **神技：不尽斩**（伤害 100，消耗 12 MP）

### 阶段四：魔王城堡（BOSS 战）

- **地点**：魔王城堡 `T`，地图右上角
- **描述**："巨大的黑色城堡，散发着压迫感。"
- **BOSS**：绝望黑龙
  - **一阶段**（HP > 140）：HP: 280, MP: 100, ATK: 60, DEF: 20, 经验: 200
  - **技能**：龙焰吐息（伤害 50，20% 穿甲）、暗影裂爪（伤害 35，50% 穿甲，吸取 MP）
  - **二阶段**（HP ≤ 140）：攻击力提升 1.5 倍，使用技能概率提高
- **胜利后**：播放通关动画，游戏结束

每局游戏在地图道路上随机生成 3~5 个事件，踩上去即触发：

| 事件名 | 对话文本 | 奖励 |
|--------|---------|------|

## 玩家属性

| 属性 | 初始值 | 说明 |
|------|--------|------|
| 姓名 | 勇者 | 固定 |

### 升级系统

- **初始经验阈值**：50，每次升级后阈值 ×1.2
- **每次升级提升**：HP +20, MP +10, 攻击 +5, 防御 +3
- 后续升级增幅递增（HP 增量每级 +20，攻击增幅 ×1.1 等）

## BOSS 战机制

### 绝望黑龙 — 完整行为

**一阶段（HP > 140）**：
- 60% 概率释放「龙焰吐息」（伤害 50，忽略 80% 防御 → 仅计算 20% 防御）
- 30% 概率释放「暗影裂爪」（伤害 35，忽略 50% 防御，并吸取玩家 8 MP）
- 10% 概率普通攻击

**二阶段（HP ≤ 140）触发台词**：
> "💢 绝望黑龙发出震天怒吼，鳞片燃起深红光芒，进入【二阶段】！"

**二阶段强化**：
- 龙焰吐息伤害提升至 75（50 × 1.5），MP 消耗 12
- 暗影裂爪伤害提升至 52（35 × 1.5），MP 消耗 8，吸取 8 MP
- 65% 概率龙焰吐息，35% 概率暗影裂爪

### 战斗通用机制

- **暴击率**：15%，暴击伤害 ×2
- **闪避率**：10%，完全躲避一次攻击
- **逃跑率**：50%，逃跑成功后回到上一安全位置

## 操作指令

### 探索模式

| 指令 | 说明 |
|------|------|
| `w` / `a` / `s` / `d` | 移动（上/左/下/右） |
| `go north` / `south` / `west` / `east` | 方向移动（全称） |
| `m` | 显示地图 |
| `status` | 查看玩家状态 |
| `bag` / `inventory` | 打开背包（可使用道具） |
| `take` | 捡起地面物品 |
| `talk` | 与当前场景 NPC 对话 |
| `help` | 显示帮助信息 |
| `quit` | 退出游戏 |

### 战斗模式

| 指令 | 说明 |
|------|------|
| `attack` | 普通攻击 |
| `skill` | 打开技能列表，输入编号释放 |
| `item` | 打开背包，输入编号使用道具 |
| `escape` | 尝试逃跑（50% 成功率） |
| `status` | 查看玩家状态 |
| `quit` | 退出游戏 |
| `back` / `b` | 在技能/道具子菜单中返回上级 |

## 地图系统

- **尺寸**：12 × 6 网格
- **边缘**：四周为 `#` 山脉，不可通行
- **内部**：随机生成 20% 的山脉障碍
- **连通性保证**：使用 BFS（PathFinder）检查新手村到城堡的通路，若不通则打通一条路径
- **地点随机**：迷雾森林和黑暗洞穴在空白路径上随机放置

### 地图图例

| 符号 | 含义 |
|------|------|
| `@` | 玩家当前位置 |
| `V` | 新手村 |
| `F` | 迷雾森林 |
| `C` | 黑暗洞穴 |
| `T` | 魔王城堡 |
| `?` | 随机事件 |
| `#` | 山脉（不可通行） |
| `.` | 道路（可通行） |

## 项目架构

```
src/com/hdh/txtrpg/
├── MainGame.java              # 主游戏循环，命令处理
├── engine/
│   └── BattleEngine.java      # 战斗引擎（暴击/闪避/逃跑/BOSS阶段）
├── entity/
│   ├── Character.java         # 角色抽象类（HP/MP/ATK/DEF）
│   ├── Player.java            # 玩家类（等级/经验/技能/背包）
│   ├── Enemy.java             # 敌人类 + 工厂方法
│   ├── NPC.java               # NPC 类（名称+对话）
│   ├── Location.java          # 场景类（描述/出口/物品/敌人/NPC）
│   ├── GameWorld.java         # 世界管理器（地图/坐标/事件）
│   ├── Event.java             # 随机事件（对话+奖励）
│   ├── Inventory.java         # 背包系统
│   ├── Item.java              # 物品接口 → HealthPotion / ManaPotion / EnhanceFruit
│   └── Skill.java             # 技能接口 → Fireball / Heal / Blitz / InfinitySlash / DragonBreath / ShadowClaw
├── map/
│   ├── MapGenerator.java      # 地图生成器接口
│   ├── DefaultMapGenerator.java # 默认随机地图生成器
│   ├── MapData.java           # 地图数据容器
│   ├── PathFinder.java        # BFS 连通性验证
│   └── Coord.java             # 坐标数据结构
└── util/
    ├── MapConstant.java       # 地图常量（符号/尺寸）
    └── DirectionConstant.java # 方向常量（w/a/s/d ↔ north/south/west/east）
```

### 设计模式

- **策略模式**：`MapGenerator` 接口 + `DefaultMapGenerator` 实现，可替换为迷宫/预设地图生成器
- **工厂方法**：`Enemy.createGoblin()` / `createDragon()` / `createSlime()` / `createSkeleton()`
- **接口多态**：`Item` 接口（HealthPotion / ManaPotion / EnhanceFruit）和 `Skill` 接口（6 种技能实现）
- **模板方法**：`Character` 抽象类定义通用属性与方法，`Player` / `Enemy` 各自实现 `displayStatus()`
